## Purpose / risk
Real row 1 of `test_csvimport/Performance.csv` (symbol, qty, buy and sell price, P&L, both timestamps, duration) was copied, with its fill IDs replaced, into several tests and fixtures outside `csv_import/`. TASK-037 replaces the real export and the copies inside its own files, but these copies would remain in the tracked tree. Without fill IDs the values are weaker evidence of a real trade, so the owner decides first whether they must go.

## Trigger / reproduction
Repository is public (`README.md:155-157`); the files are readable on GitHub at HEAD.
