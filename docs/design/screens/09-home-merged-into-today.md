# 9 · Home: merged into Today

Build 6 makes **Today** the landing page, so there is no separate Home route. Mockup `Home.dc.html` is kept for
ideas that belong on Today ([08](08-today.md)) or elsewhere:

| Home element | Where it goes |
|---|---|
| Greeting and "last session" line | Today header (optional) |
| "Continue: review Monday" card | Today action "Review session" → Build 22 daily review |
| Accounts today with closest limit | Today all-accounts cards (Build 21), using engine values only |
| Recent days (`DayCard`) | Journal (Build 20) or Today |
| Quick actions | Today actions; Import CSV stays the header's primary action |
| "Everything in FundedFlow" tiles | Not needed: the sidebar has five items |
