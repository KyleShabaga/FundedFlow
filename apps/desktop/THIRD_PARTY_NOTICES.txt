FundedFlow third-party notices
==============================

About this file
---------------

FundedFlow 0.1.0 for Windows x64 (x86_64-pc-windows-msvc) includes the third-party components listed below. Each is licensed by its own authors under the licence named in its entry; the full licence texts follow at the end, each printed once and referenced by its [T] number.

This build includes 232 Rust crates, 58 npm packages and 3 fonts: 293 components, with 38 distinct licence texts.

FundedFlow itself is not open source. Its own terms are in the LICENSE file installed next to this one.

What is included
----------------

Rust crates: the normal (non-dev, non-build) dependencies of the FundedFlow app for the x86_64-pc-windows-msvc target, as resolved by Cargo.lock and reported by cargo-about. Crates used only on other platforms are not included.

npm packages: the production dependency tree of apps/desktop and packages/domain in package-lock.json, whose code Vite bundles into the app. Development tools and type packages are not included.

Fonts: Inter, Space Grotesk and JetBrains Mono, bundled from their Fontsource packages under the SIL Open Font License 1.1.

Where a component offers a choice of licences, the entry names the one used here and the full choice it was taken from.

Not covered
-----------

Microsoft Edge WebView2 Runtime: not bundled. The installer downloads Microsoft's bootstrapper only on a computer without the runtime, and Microsoft licenses it under its own terms.

NSIS (Nullsoft Scriptable Install System): builds the installer and is not part of the installed app.

How to regenerate
-----------------

From the repository root, run `npm run notices` (needs cargo-about 0.9.2) and commit the result. CI runs `npm run check:notices`, which fails when a dependency changes without this file being regenerated.

pub fn escape(text: &str) -> String {
    let mut quoted = String::new();
    escape_into(text, &mut quoted);
    quoted
}

fn escape_into(text: &str, buf: &mut String) {
    buf.reserve(text.len());
    for c in text.chars() {
        if is_meta_character(c) {
            buf.push('\\');
        }
        buf.push(c);
    }
}

fn is_meta_character(c: char) -> bool {
    match c {
        '\\' | '.' | '+' | '*' | '?' | '(' | ')' | '|' | '[' | ']' | '{' | '}' | '^' | '$'
        | '#' | '&' | '-' | '~' => true,
        _ => false,
    }
}
